# NetLink DL/T 645‑2007 电表采集设计

- 日期：2026-11-13
- 状态：首版已实现，本地模拟通过，待现场实表联调

## 1. 首版范围

NetLink 作为 DL/T 645‑2007 只读主站，通过 RS‑485 串口直连或 TCP 透明传输读取真实电表。一个连接可配置多块电表，每块表有独立的通信地址、轮询周期和点表。点表支持选择内置指标、添加自定义指标、周期轮询和手动读取一次。页面显示实时读数与采集状态，报文监视保留收发明细。

本期范围限于读通信地址和数值采集。写表、645 从站模拟、任意十六进制发帧、批量发现表地址、历史存储及曲线留待后续需求。TCP 验收所用的模拟网关是测试端点。

## 2. 现场操作

1. **新建连接。** 选「DL/T 645‑2007 串口主站」或「DL/T 645‑2007 TCP 透传主站」。串口配置端口、波特率、校验、停止位和应答超时。TCP 配置网关主机、端口和应答超时，电表侧的串口参数在网关上设置。两个入口均发送标准 645 字节流，TCP 侧直接接入透明传输端口。
2. **添加电表。** 表地址用保留前导零的 12 位十进制字符串保存。同一连接下地址唯一。多表接入时按已知地址逐块添加。地址未知时，只接一块表，打开连接并点「读取表地址」，校验应答后填入正在编辑的设备，确认保存后生效。按钮旁提示实际链路只能接一块表，软件中的设备数量无法证明现场接线情况。两块表的地址均未知时，逐块读址再并到同一总线。[DL/T 645‑2007 §7.4](https://www.dlt698.com/sg64507pro.pdf)
3. **添加指标。** 设备点表提供「选择指标」和「新建自定义指标」。内置目录按类分组，勾选确认后加入当前电表，已存在的 DI 显示为已添加。同一表的 DI 唯一，不同表可以配置相同 DI。支持修改名称、单位和倍率，以及移除点位或关闭该点的轮询。
4. **读取与诊断。** 可以暂停设备周期轮询并保持连接打开，然后对任意已配置指标执行「读取一次」。开启轮询时，手动读取在当前事务结束后调度。手动和周期读取都更新同一行，报文按连接和设备过滤。连接关闭或正在重连时，手动读取给出明确状态。

「测试连接」检查串口能否打开或 TCP 端口是否可达。实表是否可读，由读地址或读指标的结果确认。测试串口时复用实际串口参数，运行中的串口由现有连接独占。

## 3. 点表与换算

| 指标组 | 首版目录 | 标准 DI（界面顺序） | 单位 |
| --- | --- | --- | --- |
| 电量 | 当前正向、反向有功总电量 | `00010000`、`00020000` | kWh |
| 电压 | A、B、C 相 | `02010100`、`02010200`、`02010300` | V |
| 电流 | A、B、C 相 | `02020100`、`02020200`、`02020300` | A |
| 有功功率 | 总有功功率 | `02030000` | kW |
| 功率因数 | 总功率因数 | `02060000` | 无量纲 |
| 频率 | 电网频率 | `02800002` | Hz |

内置项随程序提供 DI、字节数、符号规则和小数位，配置值依据标准附录 A 及适用备案核对。目录表示可选的数据项，DSZ9599 三相三线实表的分相支持情况在联调记录中逐项确认。电表明确返回无此数据时标记为「不支持」，无应答时标记为「超时」。[DL/T 645‑2007 协议正文及备案](https://www.dlt698.com/sg64507pro.pdf)

自定义指标填写名称、8 位十六进制 DI、解析格式、数据字节数、小数位、单位和倍率。首版支持每个 DI 解析一个数值，提供低字节在前的 BCD（可选最高位符号，1–6 字节）和二进制整数（无符号或补码，1–4 字节）。复合数据、文本及后续帧在报文监视中保留原始应答，点表提示当前格式无法解析。配置在前端即时校验，并在后端保存和启动入口复核。应答长度、BCD 数字位和解码结果均需校验。

`电表读数 = 解码数值 ÷ 10^小数位`，`显示值 = 电表读数 × 倍率`。倍率默认 `1`，按点位设置。只有现场确认电表回传值为二次侧量且需要一次侧显示时，才填写相应的 CT/PT 倍率。界面可查看换算前的电表读数。连接、设备和点位配置随工程保存，采集值与报文保存在运行时。

## 4. 工程模型与接入点

| 层 | 设计 |
| --- | --- |
| 工程模型 | 在 `netlink-core/src/model.rs` 的 `Transport` 新增 `dlt645_serial` 和 `dlt645_tcp`。在 `Connection` 增加默认空、为空时省略的 `dlt645_meters`，参照现有 CAN 专用配置方式。电表存设备 ID、名称、通信地址、启用状态、轮询开关及周期。点位存 ID、名称、DI、解码参数、单位、倍率及轮询开关。工程保存和加载覆盖新类型，并验证旧工程可打开和原样保存。 |
| 协议与运行时 | 在 `netlink-core/src/protocol/dlt645/` 实现组帧、拆帧、数值解析和采集循环。串口与 TCP 共用 645 事务与调度逻辑。`RuntimeManager` 负责连接启停、状态和报文事件。串口打开复用现有端口配置逻辑，TCP 复用已有连接状态与退避重连方式。 |
| 桌面接口 | `netlink-app` 增加读通信地址、读取一次两个结构化命令。后端核验连接协议、设备与点位归属，运行时通过现有推送链路发送 645 点位快照。地址读取可在电表配置保存前执行。 |
| 界面 | `DeviceTree` 增加 645 的连接和电表配置。沿用现有点表区域、选择抽屉、报文监视和连接状态样式。645 使用 DI 列与只读操作，现有 Modbus 的区号、寄存器地址、扫描和写入入口仍由对应协议提供。Tauri 与浏览器 mock 同步接口。 |

645 点位快照包含最近一次成功读数、换算值、成功时间及最近尝试状态。初次读取前值为空。后续失败时保留上次成功值和时间，状态显示本次的超时、异常应答、校验错误或解析错误。连接离线时标为离线，暂停轮询后可继续手动更新。报文监视复用 `FrameEvent`，显示收发方向、HEX、表地址、命令和可判定的 DI，异常帧或超时附失败原因。

## 5. 采集与通信规则

- 一个连接只有一个 I/O 所有者，同时仅有一个在途请求。单表读址、手动读和周期读走同一调度器。按设备到期时间取轮询任务，逾期轮次合并，避免积压。手动请求可在两笔事务之间插入。暂停轮询后，当前事务可完成，后续周期请求停止。
- 周期轮询按同一块表的标准 DI 自动合并电压、电流、有功功率和功率因数。每组有至少两个参与轮询、字节数符合标准的成员时才发块读，并按标准偏移解码各点。块读超时、异常或格式不符时，当前轮退回逐项读取，记忆失败直到连接重新启动。手动「读取一次」直接读指定点。
- 协议层生成读数据 `0x11` 和读地址 `0x13` 请求。解析器处理可选 `FE` 前导、两个 `68` 帧头、地址、控制码、长度、累加校验及 `16` 结束符。按标准处理地址和 DI 的线序、数据域 `±0x33`，并匹配当前事务的表地址、控制码和 DI。读址校验帧头地址与应答数据中的地址一致。串口和 TCP 都按字节流拆帧，支持分片、多帧同批到达和校验失败后重新同步。[DL/T 645‑2007 §6–7](https://www.dlt698.com/sg64507pro.pdf)
- 正常应答并且成功解码后才更新读数。地址或 DI 不匹配的帧仅记日志，异常应答按错误字显示。单个点超时或解析失败后继续调度下一点或下一块表。串口接收在超时后重新同步，TCP 断开后清空接收缓冲并退避重连。645 无事务编号，同一地址和 DI 的迟到应答有歧义，超时后等待链路恢复静默再发起后续事务，首版避免立即重试同一请求。
- 建议默认值为串口 `2400 / 8E1`、应答超时 `1000 ms`、电表轮询周期 `1000 ms`，现场可改。轮询周期为目标间隔，实际更新速度取决于点位数、波特率、应答时间及超时情况。TCP 透传使用网关配置的端口。关闭连接时结束待处理的手动请求并释放 I/O。

## 6. 验收

| 环境 | 操作 | 通过条件 |
| --- | --- | --- |
| 自动测试 | 固定协议样帧、分片和连续帧、错误校验与异常应答、地址和 DI 不匹配、BCD 符号和倍率 | 字节级结果匹配，错误应答不会更新成功值或写到另一块表，坏帧后可恢复拆帧 |
| 自动测试 | 新旧工程读写，新增 645 命令，Modbus 与 CAN 回归 | 地址保留前导零，645 配置可重载，旧工程可正常加载，其他协议原有用例通过 |
| RS‑485 实表 | 两块表分别单独接入并读址，保存后并到同一总线；配置相同 DI 后轮询 | 自动填入各自地址，两表读数和报文归属正确；可与表显或已知参考值对照 |
| RS‑485 实表 | 勾选内置指标并添加至少一个实表支持的自定义数值 DI；停轮询后手动读取；让一块表暂时离线 | 点表显示读数、单位和成功时间；读取一次只更新目标点；离线表显示失败且保留上次成功值，另一块表继续采集 |
| TCP 模拟网关 | 本地 TCP 端点接收原始 645 请求并模拟两块表的应答，覆盖拆包、连续帧、延迟、超时、断线和重连 | 串口与 TCP 使用同一协议语义，手动读取与轮询结果正确；单点超时不阻断其他点，重连后恢复采集 |

现场记录两块表的型号、实际串口参数、DSZ9599 的分相 DI 支持情况及读数口径。TCP 首版以模拟网关结果验收，实体网关的兼容性留到设备可用时补验。

本地验证覆盖串口 I/O 模拟、TCP 双表模拟、桌面版与模拟网关联调、工程配置回读和工作区回归。串口实物链路及实体网关仍需现场验证。
